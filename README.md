# LG Aimers 9기 — 투구 제구 성공 확률 예측

[대회 페이지](https://dacon.io/competitions/official/236743/overview/description)

투구 단위로 다음 투구의 제구 성공 확률 `P(control_success=1 | 투구 직전 정보)` 를 예측한다.
학습 2019~2024 (1,475,092행), 평가 2025 (245,789행, 비공개), 지표 Brier Skill Score.

## 점수를 만든 핵심 아이디어

1. **시즌 당해 성적 분리 (+47점 누적).** 공식 `asof_*`는 통산 누적이라 베테랑일수록
   올해 성적이 희석된다. `asof_pitcher_n`이 학습 데이터 행 수와 일치하는 구조를 이용해
   직전 시즌 종료 상태 `(n0, r0)`를 학습 데이터 상수로 만들어 두면
   `당해 성공률 = (N·R − n0·r0)/(N − n0)` 로 각 행에서 올해분만 복원할 수 있다.
   그 행 자신의 값 + 학습 상수만 쓰므로 행 독립 규정을 지킨다. → `src/script.py` `apply_carry_state`

2. **walk-forward 평균 이동 (+77.7점).** 과거 fold들의 (실제 평균 − 예측 평균) 잔차 평균을
   다음 해에 적용. 시즌 드리프트(성공률 매년 하락)를 모델 밖에서 처리한다.

3. **팀 파이프라인 병합 (+61.6점).** 서로 다른 설계(역할/레버리지 프로파일, Marcel 투영,
   halflife 시즌 감쇠, 단조 제약, ID 제거+carry 테이블)의 CatBoost와 우리 임베딩 NN의
   오차 상관이 낮아 55:45 혼합이 양쪽 단독보다 우수했다.

4. **로그오즈 샤프닝 (+10.1점).** 신뢰도 곡선 기울기가 1.08로 1을 넘어(예측이 실제보다
   덜 퍼짐) 로그오즈를 1.08배 확장. 중심은 학습 OOF 평균으로 고정해 test 정보 미사용.

5. **시드 앙상블은 모델에 따라 다르다.** NN은 시드 잡음 V≈47e-5로 시드 평균이 크게 유효
   (3→16시드 +12e-5), 강규제 CatBoost(l2=1000)는 V≈0.14e-5로 시드 확장이 무의미(+0.04점 실측).

## 실패에서 확정한 사실 (재현 방지용)

- **행 피처 추가는 1e-5 한계.** 공식 `asof_*`가 행 수준 정보를 사실상 다 담고 있다.
  도메인 파생 이후 시도한 피처 대부분이 이 벽에 걸렸다.
- **스태킹/게이팅/가중치 최적화 전부 무효.** 고정 55:45 혼합이 이미 최적 선형결합
  (로짓 2개 로지스틱과 차이 -0.42e-5). 문맥 의존 가중은 항상 악화.
- **손실함수 교체 무효.** Logloss와 Brier(제곱손실)는 둘 다 proper라 최적해가 같고,
  같은 그릇에서 손실만 바꾸면 오차 상관 0.9999로 다양성이 생기지 않는다.
- **원시 Brier로 NN 학습 절차를 판단하면 속는다.** 에폭/스케줄 변경 이득의 80% 이상이
  예측 평균 이동이었고, 그건 shift가 이미 처리한다. 반드시 평균정렬 후 비교.
- **시즌 내 잔차 구조는 암기다.** 랜덤 분할 교차적합에서 잔차 예측이 되는 것처럼 보여도
  (+30e-5), 투수 단위 분할로 바꾸면 소멸한다(-32e-5) — 투수별 시즌 편차를 외운 것.
- **리더보드 점수차로 비공개 정답을 역산하지 않는다** (규정 위반, 실격 사유).
  test 내부 집계가 필요한 피처(월별 당해 성적 등)는 백테스트가 아무리 좋아도 배포 불가.

## 검증 프로토콜 (이 저장소의 모든 숫자 기준)

```
fold:        2019~2021 → 2022  /  2019~2023 → 2024
채점 행:      (game_type=="R") | (season>=2023)   ← 2025에 존재하는 행 유형만
비교:        예측 평균을 실제 평균에 맞춘(mean-align) Brier
판정:        짝지은 표준오차(paired SE), 두 fold 부호 일치 요구
잡음 바닥:    시드 재학습 SD 2.4~2.8e-5 (두 모델 비교 1σ ≈ 4e-5)
환산:        Brier 1e-5 ≈ 리더보드 4.0점
```
