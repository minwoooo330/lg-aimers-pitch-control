# 최고점 파이프라인 전달 (리더보드 1127.0635)

## 1. 구조

```
최종 예측 =
    0.95 x [ 0.55 x CatBoost 45개 평균  +  0.45 x 임베딩NN 16시드 평균 ]
  + 0.05 x 전채널 시즌당해 NN
       |
       v  로그오즈 샤프닝   z' = c + 1.08 x (z - c),  c = -0.027330
       v  평균 이동        p' = p - 0.013910949
```

CatBoost 45개 = 5개 설정 x 9개 시드.
설정은 `v7_pipeline.py`의 `ENSEMBLE`에 있습니다(d7/d6/d7reg/d8/slow).

## 4. 이 구조에서 점수를 만든 것들 (기여 순)

1. **시즌 당해 성적 분리 (+47점).** `asof_*`는 통산 누적이라 베테랑일수록 올해 성적이 희석됩니다.
   `asof_pitcher_n`이 학습 데이터 행 수와 정확히 일치하는 성질을 이용해
   직전 시즌 종료 시점 상태 `(n0, r0)`를 학습 데이터에서 미리 계산해 두면
   `당해 성공률 = (N x R - n0 x r0) / (N - n0)` 로 각 행에서 올해분만 뽑아냅니다.
   그 행 자신의 asof 값 + 학습 데이터 상수만 쓰므로 규정 위반이 아닙니다.
   `script.py`의 `apply_carry_state` 참고.

2. **평균 이동 shift (+77.7점, 최초 도입 시).** 과거 fold 잔차 평균을 다음 연도에 적용합니다.
   현재 값 `-0.013910949`. 주의: 이 값을 임의로 줄였다가 -7.49점을 맞은 적이 있습니다.

3. **로그오즈 샤프닝 scale 1.08 (+10.13점).** 신뢰도 곡선 기울기가 1.076~1.087로
   1을 넘어서(예측이 실제보다 덜 퍼져 있음) 로그오즈를 1.08배로 벌립니다.
   중심 `c`는 학습 OOF의 예측 로그오즈 평균으로 고정해 test 정보를 쓰지 않습니다.

4. **CatBoost + NN 혼합 (+17점 상당).** 두 계열의 예측 상관은 0.9658입니다.
   비중 0.55/0.45는 두 fold의 타협 최적점이며, 재최적화하면 오히려 나빠집니다.

## 5. 검증 규격 (숫자를 비교하려면 맞춰야 합니다)

```
2019~2021 -> 2022 검증 / 2019~2023 -> 2024 검증
채점 대상 행: (game_type=="R") | (season>=2023)
비교 전 예측 평균을 실제 평균에 맞춘 뒤(mean-align) Brier 계산
```

**평균정렬은 반드시 하셔야 합니다.** 안 하면 평균이 옮겨진 것만으로 Brier가
10e-5 넘게 좋아 보이는데, 그 효과는 어차피 shift가 처리하므로 실제 이득이 아닙니다.
저희가 오늘 이걸로 한 번 잘못 판단했습니다.

현재 성적:
```
2022 fold  0.24802890
2024 fold  0.24735441
```

시드만 바꿔 재학습했을 때의 Brier 변동 폭은 2022 2.37e-5 / 2024 2.80e-5입니다.
**두 모델 비교 시 1시그마가 약 4e-5이므로 그보다 작은 차이는 잡음입니다.**

Brier 1e-5 = 약 4.0점입니다.

## 6. 규정 주의

- test 각 행은 독립 예측이어야 합니다. 한 행만 넣었을 때와 전체를 넣었을 때 값이 같아야 합니다.
- 학습 데이터로 미리 만든 표를 test 행이 조회하는 것은 허용됩니다.
- **`apply_platoon` / `apply_bplatoon`에 행 독립성 버그가 있었습니다.** 반대손 값을
  배치 max/min으로 계산해 단독 행 예측이 1.2e-2 달라졌습니다. `other = 3 - hand`로
  고쳤고 전체 배치 예측은 수학적으로 동일해 점수는 안 변합니다. 원본 코드를 쓰신다면
  이 부분을 확인해 주세요.
