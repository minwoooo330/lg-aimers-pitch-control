# 인계 브리프 — LG Aimers 투수 제구 성공 확률 예측

이 문서는 **사실과 규정만** 담는다. 무엇이 유망한지에 대한 판단은 담지 않는다.

## 1. 과제

각 투구에 대해 `P(control_success=1 | 그 투구 직전까지 알 수 있는 정보)`를 예측한다.
학습 2019~2024, 평가 2025(비공개). 제출값은 확률.

**제구 성공의 공식 정의(운영진 공지):** 공의 **위치** 기준이며 아래 3가지가 실패, 그 외 유효 투구는 성공.
1. 스트라이크존 가운데 부근 (실투)
2. 존에서 크게 벗어남
3. 포수 요구 방향과 반대

판정(볼/스트라이크) 기준이 아니라 위치 기준이다. 3번은 포수 사인 데이터가 제공되지 않는다.

## 2. 평가

`Score = max(0, 100000 x (1 - Brier / (r(1-r))))`, r은 2025 전체 실제 성공률(비공개).
`r ~ 0.4726` 가정 시 **Brier 1e-5 개선 = 약 4.0점**.
Public = 전체 test 100%, 대회 종료 시점 점수가 그대로 Private.

## 3. 규정 (위반 시 실격)

- **각 test 행은 독립 예측.** 판별법: 그 행 하나만 넣었을 때와 전체를 넣었을 때 예측이 같아야 한다.
- test 내부의 선수/팀/월 단위 집계, target encoding, 행 순서 기반 rolling/lag, test 분포를 본 사후 보정 **전부 금지**.
- **학습 데이터에서 미리 계산해 저장한 통계표를 test 각 행이 독립적으로 조회하는 것은 허용.**
- 리더보드 점수로 모델/가중치를 고르는 것은 허용. 단 여러 제출의 점수 차로 비공개 정답 평균이나 개별 행 값을 역산하는 것은 금지.
- 제출 ZIP 최상단에 `model/`, `script.py`, `requirements.txt`. 서버가 `data/`, `output/` 추가.
- 245,789행 추론 10분 이내, 패키지 설치 10분 이내. 인터넷 불가.
- 서버: Ubuntu 22.04.5, Python 3.11.15, 6 vCPU, RAM 28GB, L4 GPU 22.4GiB.
- 하루 최대 5회 제출.

## 4. 데이터

- `data/train.csv` 1,475,092행 x 49컬럼 (입력 47 + row_id + control_success)
- `data/test.csv` 5행 샘플 (실제 hidden test 아님)
- `data/trackman_history.csv` 1,793,078행 x 30컬럼, **2019~2024만. 2025 없음.**
  컬럼: rel_speed, spin_rate, induced_vert_break, horz_break, extension, rel_height, rel_side,
  zone_speed, tagged_pitch_type 등. **공 위치(플레이트 X/Y)와 스윙 여부는 없다.**
- Trackman의 `pitcher_trackman_id`와 메인 `pitcher_id`는 값 교집합이 0이다(별도 익명화).
- `asof_*` 컬럼은 그 투구 직전까지의 누적/최근 이력이며 공식 제공이다.
- `game_type`: R=1군, F=퓨처스.

## 5. 현재 성적 (기준선)

리더보드 **1127.0635**. 1위 약 1209. 본선 진출 기준 상위 100위권.

챔피언 구조:
```
CatBoost 앙상블 55% + 임베딩 NN 45%
  -> 로그오즈 샤프닝 (center -0.027330, scale 1.08)
  -> shift -0.013911
```

## 6. 검증 규격

시간 순서를 지킨 walk-forward를 쓴다.
```
2019~2021 -> 2022 검증
2019~2023 -> 2024 검증
```
**채점 대상 행:** `(game_type=="R") | (season>=2023)`.
이유: 2025 test에는 1군 행과 2023년 이후 퓨처스 행만 존재하므로, 2022년 이전 퓨처스는
평가 대상이 아니다(퓨처스는 2023년에 라벨 규칙이 바뀌어 성공률이 0.71 -> 0.47로 급변했다).

**비교 시 예측 평균을 실제 평균에 맞춘 뒤(mean-align) Brier를 계산한다.** 그래야 평균 보정
효과와 모델 자체의 개선이 섞이지 않는다.

현재 챔피언의 fold 성적:
```
2022 fold  n=217,024  Brier 0.24804366
2024 fold  n=253,507  Brier 0.24736683
```

`oof/champion_oof_2022_2024.csv.gz` 에 두 fold 전체의 행별 예측이 있다:
`row_id, season, game_type, control_success, v7(CatBoost), nn(신경망), champion(혼합)`

새 모델을 만들면 이 파일과 row_id로 합쳐서 혼합 기여를 바로 계산할 수 있다.

## 7. 판정에 쓰는 잡음 수준 (실측)

같은 설정에서 `random_state`만 바꿔 재학습했을 때의 Brier 변동:
```
2022 fold  시드 표준편차 2.37e-5
2024 fold  시드 표준편차 2.80e-5
```
두 모델을 비교할 때의 1시그마는 `sqrt(2) x SD`이므로 2024에서 약 3.96e-5다.
단, 같은 베이스에 소폭 얹는 짝지은 비교는 공통 성분이 상쇄되어 표준오차가 훨씬 작다.
