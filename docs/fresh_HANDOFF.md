# 인계 파일 — 2026-09 세션 (백지 재구축, CatBoost 단일계열 파이프라인)

이 문서는 이 세션에서 완전히 처음부터(과거 실험 미참조) 만든 파이프라인의 인계 자료다.
`BRIEF.md`(대회 규정/현재 리더보드 상황), `TRIED.md`(이전 세션의 압축 요약, **이 문서와 다른 작업**)와는
별개 파일이다. `TRIED.md`는 임베딩 NN·Trackman 등 이번 세션에서 손대지 않은 내용이니 혼동하지 말 것.

## 이 세션이 한 일 (요약)

원본 47피처 + 파생 1개 → CatBoost 5시드 앙상블 → walk-forward 편향 기반 shift 보정.
"1(베이스라인)→2(EDA&FE)→3(모델선택·튜닝)→4(앙상블·안정화)" 순서로 각 결정을
두 개의 시간분할 fold에서 검증하며 진행했다. **모든 실험은 가설을 먼저 세우고 검증하는 방식**으로
했고, "왜 되는지/안 되는지"를 매번 확인했다(단순 성능 비교만으로 채택하지 않음).

## 재현/실행 방법

```
fresh/
├── src/
│   ├── validation.py    # fold 정의, brier/mean_aligned_brier, evaluate()
│   ├── features.py      # CATEGORICAL_COLS, NUMERIC_COLS, DERIVED_NUMERIC_COLS, prepare_features()
│   ├── encoders.py       # frequency/OOF target encoding 유틸 (Step2-1용, 최종 미채택)
│   ├── model_config.py   # DEFAULT_HGB_PARAMS
│   └── final_model.py    # 최종 파이프라인: CATBOOST_PARAMS, SEEDS, FINAL_SHIFT, train/predict 함수
├── scripts/00~15_*.py     # 실행 순서대로 번호 부여, 각 파일 docstring에 가설과 근거 명시
├── models/catboost_seed{42,7,2024,13,77}.cbm   # 2019~2024 전체로 학습된 최종 5개 모델 (재학습 불필요)
├── results/*.csv(.gz)     # 각 실험의 수치 결과, 시드별 원본 예측(11_seed_preds_*)
└── HANDOFF.md            # 이 파일
```

가장 빠른 재현: `src/final_model.py`의 `load_ensemble(Path('models'))` → `predict_final(models, df, categories)`.
`categories`는 `features.build_categories(전체train로드)`로 만든다(카테고리 집합 고정용, 타깃 미사용).

## 검증 설계 (Step 0)

- **왜 이 설계인가**: train을 season×game_type으로 직접 집계해보니 퓨처스(F)가 2023년에
  성공률 0.70대→0.47대로 급락. 사용자 확인: KBO ABS(자동 볼판정)가 퓨처스 2023, 1군 2024 도입.
  즉 2025 test는 두 리그 모두 ABS 체제인데, 2022년 이전 데이터로 검증하면 이미 사라진 구체제를
  기준으로 모델/피처를 고르게 되는 문제가 있음.
- **main fold**(주판정): train season≤2023(전체) → valid season==2024. 두 리그 다 ABS 체제라 2025를
  가장 잘 대표.
- **ref fold**(보조/안정성만, 이걸로 채택 여부 결정 안 함): train season≤2021 → valid season==2022.
  둘 다 ABS 이전이라 2025 대표성 없음.
- **비교 지표**: `mean_aligned_brier` — 예측 평균을 그 fold의 실제 평균에 맞춘 뒤 Brier 계산.
  calibration 효과와 모델 자체 개선을 분리하려는 목적. **주의**: 이것만 보면 "보정 자체가 진짜
  이득인지"는 판단 못 함 → Step4에서 별도로 raw Brier로 정직하게 재검증함(아래 참고).

## 판정 문턱 (노이즈 바닥)

`HistGradientBoostingClassifier`는 데이터 1만 행 초과 시 `early_stopping='auto'`가 기본값이라
내부적으로 무작위 검증 분할을 함 → 불필요한 잡음원. **비교 실험엔 반드시 `early_stopping=False`.**
이걸 끈 상태에서 시드만 바꿔 재학습한 잡음 수준(placebo 랜덤피처로 재확인):
- main fold: 문턱 ≈ **5e-5** 이하 차이는 판정 불가
- ref fold: 문턱 ≈ **2e-5** 이하 차이는 판정 불가

**이 두 값보다 작은 개선/악화는 "신호 없음"으로 처리**했다. 애매한 후보는 3시드 평균으로 재확인.

## Step 2: EDA & 피처 — 11개 가설 중 1개만 채택

모든 파생 피처는 "이미 raw로 있는 컬럼들의 산술 재조합"과 "raw로는 트리가 재현 불가능한 정보"
두 부류로 갈렸고, **후자만 통했다.**

중복이었다. 유일하게 통한 건 "서로 다른 시간창(커리어 vs 최근5경기)의 차이"였다 — 이건 raw
컬럼 두 개만으로 트리가 축분할로 재현하기 어려운 진짜 새 정보였기 때문으로 해석.

**안 해본 것(리스크 대비 기대이득 낮다고 판단해 보류)**: 타자쪽 season-only 통계 자체 구축(투수의
prev_game 컬럼을 흉내내려면 직접 시간정렬+shift(1) 구현 필요, 누수 위험 실비용 큼),
Trackman ID 매핑(투수 792명 vs Trackman 906명 값 교집합 0, 매핑 자체가 간접추정이라 신뢰 낮고
오버피팅 우려로 사용자와 합의해 보류), 군집화/그래프임베딩(raw 재조합 패턴 반복 예상 + 누수 리스크).

## Step 3: 모델 선택 — CatBoost 확정

5개 계열을 같은 피처셋(원본47+파생1)으로 동일 조건 비교(단일 시드, 순한 기본 파라미터):

| 모델 | main(mean_aligned brier) | ref |
|---|---|---|
| HistGradientBoosting | 0.248201 | 0.243523 |
| LightGBM | 0.248231 | 0.243535 |
| XGBoost | 0.248460 | 0.243707 |
| **CatBoost** | **0.247924** | **0.243354** |
| Logistic Regression(sanity check용) | 0.250355 | 0.243962 |

CatBoost가 HGB 대비 main **+277e-5**, ref **+169e-5** — 지금까지 어떤 피처 실험보다 큰 격차.
**원인 진단**(중요, 재현 시 참고): pitcher_id/batter_id를 CatBoost native categorical(ordered
target stat)로 넣으면 오히려 **악화**(main -355e-5, ref -274e-5, 3시드 재현). 즉 CatBoost의
승리는 ID 처리 방식 때문이 아니라 알고리즘 자체(ordered boosting 등)의 우위. **raw ID 유지
결론은 모델이 바뀌어도 유지됨.**

**하이퍼파라미터 튜닝**: default/depth8/iter400+lr0.03/l2=10/l2=1 5개 후보를 2시드×2fold로 비교.
**두 fold 모두에서 일관되게 이기는 후보 없음**(main과 ref에서 순위가 정반대로 갈림) → **기본값
(iterations=200, lr=0.06, depth=6, l2_leaf_reg=3.0) 유지.** 무리한 튜닝을 하지 않는다는 원칙을
실측으로 재확인.

## Step 4: 앙상블 · 보정

**시드 앙상블(채택)**: CatBoost 5시드(42,7,2024,13,77) 확률 예측 평균.
main 개별평균 0.24793457 → 앙상블 0.24790599(**+2.86e-5**), ref 0.24335812 → 0.24332345
(**+3.47e-5**). 공짜 이득(추론비용 5배 외 다운사이드 없음)이라 채택.

**LightGBM 블렌딩(기각)**: CatBoost 5시드평균에 LightGBM을 0~30% 섞어봄. main에서 비중
올릴수록 단조 악화, 오차 상관 0.905~0.976로 높아 다양성 이득 거의 없음. **블렌딩 없이
CatBoost 5시드 단독으로 확정.**

**shift(확률 보정) — 가장 공들인 부분**:
1. walk-forward 4개 지점(train≤2020→2021, ≤2021→2022, ≤2022→2023, ≤2023→2024)에서
   raw 예측평균과 실제평균의 편향(bias=pred_mean-actual_mean) 측정:
   `bias_2021=-0.007106, bias_2022=+0.003918, bias_2023=+0.021279(F ABS전환 충격), bias_2024=+0.008664`
2. **가설(2023을 이상치로 제외)을 세웠으나 데이터로 기각함.** 근거: (a) 둘 다 "안정 레짐"이라
   믿었던 2021·2022의 편향 부호가 반대(-0.0071 vs +0.0039) — "안정기엔 편향이 작고 일관"이라는
   전제 자체가 틀림. (b) leave-one-out 검증(2회, 3점·4점 버전 모두)에서 2023 포함 평균이 제외
   평균보다 다음 해(2024) 예측을 항상 더 잘 맞힘(오차 +0.0026 vs +0.0103).
3. **최종 채택**: 4개 지점 단순평균의 음수. `FINAL_SHIFT = -0.006689` (편향 SD=0.0118로 불확실성
   큼, 인지한 채로 채택 — 표본 4개뿌이라 이 이상 정교화는 과적합 위험이 큼).
4. **정직성 검증(사용자 요청, 실제로 필요했던 검증)**: shift 계산에 2024 자신의 정보를
   전혀 안 쓰고(2021~2023만 사용, shift=-0.006030) 5시드 앙상블의 실제 2024 fold raw
   예측에 적용 → **raw Brier 0.24797689 → 보정후 0.24791170로 실제 개선(+6.5e-5)**.
   최종 채택 shift(-0.006689, 2024 정보 일부 포함)도 비슷한 수준(0.24790899)이라 과적합
   신호 없음. **결론: shift는 mean-align 지표만이 아니라 실제 raw Brier도 개선함이 확인됨.**

## 리더보드 점수 추정 (정직한 백테스트 기반)

train≤2023→2024 fold를 "가상 리더보드"로 취급, 공식 채점식 `100000×(1-Brier/(r(1-r)))`에
그 fold의 실제 r(=0.486105)을 넣어 계산:
```
raw(보정전)   Brier=0.24797689 -> 가상점수 ≈ 733
보정후(정직)  Brier=0.24791170 -> 가상점수 ≈ 759
```
**2025 예상 범위 700~780 (점추정 730~760)** 정도로 본다. 다만 shift 추정 불확실성(SD 0.0118)과
2025가 2024보다 한 해 더 먼 미래라는 점 때문에 폭넓게 잡아야 함. **참고로 BRIEF.md 기준 현재
리더보드 1위는 약 1209점, 팀 다른 참가자는 1099점대** — 이 파이프라인은 원칙을 지키며 쌓은
1차 완성 MVP이지 최종형이 아니며, 격차가 상당히 크다.

## 다음 세션에서 시도해볼 만한 방향 (우선순위 아님, 옵션 나열)

1. **두 번째로 다양한 모델 계열**: LightGBM은 CatBoost와 상관 0.90~0.98로 다양성 부족이었음
   확인됨. 신경망 계열처럼 트리와 근본적으로 다른 귀납편향을 가진 모델이면 다를 수 있음(단,
   BRIEF.md의 팀 다른 참가자 파이프라인이 임베딩NN을 썼다고 하니 참고는 가능하되, 이 세션은
   전혀 손대지 않았으므로 백지에서 직접 검증 필요).
2. **Trackman 활용**: 이번 세션은 리스크(간접 ID 매핑, 오버피팅) 때문에 사용자와 합의해 보류.
   시도한다면 매핑 신뢰도부터 독립적으로 검증(타깃 정보 없이 상태 시퀀스만으로 매칭 가능한지) 필요.
3. **리그(R/F) 분리 모델링**: 이번 세션은 단일 통합 모델만 검증. ABS 레짐 피처는 실패했지만
   "모델을 아예 나누는" 방식은 다른 실패 모드를 가질 수 있어 미검증.
4. **shift 정교화**: 현재 4점 기반 단순평균 외에 시도 안 한 방법들(리그별 차등 shift,
   추세외삽 vs 편향평균의 가중결합 등) — 단, 이번 세션에서 "구간별/상황별 차등 보정"은
   시도조차 안 했으니 유의미할 수 있지만 표본 부족 위험 여전히 큼.
5. **피처 그룹 조합 효과**: 이번 세션은 피처를 전부 개별로만 테스트했다(도메인43처럼 "약한
   피처 여러 개를 묶어서 그룹으로 넣었을 때"는 시도 안 함 — 개별로는 문턱 미달이어도 그룹으로는
   유효할 가능성 이론상 존재, TRIED.md에도 비슷한 패턴 기록 있음).
