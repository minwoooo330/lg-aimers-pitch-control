# 이미 시도한 것 (사실 기록)

**이 파일은 선택 사항이다.** 완전한 백지 상태를 원하면 읽지 말 것.
읽는 목적은 "같은 실험을 다시 하느라 남은 시간을 쓰지 않기 위해서"다.

판단이나 결론은 빼고 **무엇을 했고 숫자가 얼마였는지**만 적는다.
측정이 잘못됐다고 보면 다시 해도 된다.

단위는 e-5 Brier, +가 개선. 채점은 위 검증 규격 기준.

## 모델 계열
| 시도 | 결과 |
|---|---|
| HistGradientBoosting, CatBoost, LightGBM, XGBoost | 앙상블에 사용 중 |
| RandomForest / ExtraTrees | 단독이 60e-5 열세, 혼합 전 비중 음수 |
| FT-Transformer (GPU, 2회) | 단독은 경쟁력 있었으나 기존과 오차상관 0.95, 혼합 음수 |
| DeepFM 3종 | 혼합 음수 |
| k-NN, 로지스틱(구간화), TabM 계열 | 혼합 음수 |
| 임베딩 NN (투수/타자 임베딩 + MLP) | 채택, 현재 45% |
| 투수 임베딩을 손잡이/카운트로 분할 | 채택 |

## 앙상블 / 결합
| 시도 | 결과 |
|---|---|
| 가중치 최적화 (제약 있음/없음) | 중첩검증에서 균등가중보다 나쁨 |
| 스태킹 메타모델 (Ridge/Logistic/HGB) | 2024에서 -0.42 ~ -25 |
| 문맥의존 가중치 w(x) 게이팅 | -1.13 |
| 시드 평균 | NN에서 유효(3->8 +9.78, 8->16 +2.48), CatBoost에서 무효(3->9 +0.01) |
| 로그오즈 샤프닝 scale 1.08 | 채택, 리더보드 +10.13점 |

## 피처
| 시도 | 결과 |
|---|---|
| 도메인 파생 44개 | 채택 (초기 +18.8점) |
| 휴리스틱 파생 56개 | 2024 +2.99 / 2022 -3.32 |
| Trackman 투수 프로필 (구속/회전/무브먼트/릴리스) | 혼합 기여 ~0 |
| Trackman 타자 매핑 및 프로필 | 잔차상관 0.006, 문턱 미달 |
| 팔각도 x 좌우 매치업 | 모델 투입 시 음수 |
| 세분 구종 비중 7종 | 모델 투입 시 음수 |
| 시즌 당해 성적 (asof에서 역산) | 채택, 총 +47점 |
| 투수 x 상황 조건부 통계표 (손잡이/카운트/이닝/주자/LI 등 72조합) | 손잡이 외 전부 문턱 미달 |
| 팀 ID 범주형화, 구장 ID 파생 | 음수 |
| 월별 당해 성적 | **규정 위반**(2025 test 내부 행 참조 필요) |

## 손실함수 / 학습
| 시도 | 결과 |
|---|---|
| 제곱손실(=Brier) 직접 최적화 | 3 fold 평균 악화(2024만 개선) |
| label smoothing | 음수 |
| 최근 시즌 가중 (1.05~1.30) | 전부 악화 |
| 최근 2~3시즌만 학습 | 전부 악화 |
| 단조 제약 (asof 비율 12개) | 멤버별로 부호 엇갈림 |
| 하이퍼파라미터 튜닝 | 중첩검증은 통과했으나 실제 제출에서 -25점 |

## 보정
| 시도 | 결과 |
|---|---|
| walk-forward 편향 평균 shift | 채택, 초기 +77.7점 |
| shift를 -0.008로 축소 | -7.49점 |
